# OG CAPS asset guide

The included SVGs are original, lightweight visual placeholders. Replace them with licensed OG CAPS photography when ready.

- Campaign videos: `videos/hero-campaign.mp4` plays in the homepage hero and `videos/collection-film.mp4` plays in the lower editorial section.
- Campaign poster: `images/campaigns/hero-poster.svg` (replace the file or update the `poster` and CSS URL in `index.html` and `css/global.css`)
- Category artwork: the New Arrivals card uses `images/products/new-arrival-lookbook.jpg`; other placeholder artwork is under `images/categories/`.
- Product photography: supplied photos are in `images/products/` and assigned to the sample catalog products; store further images in this folder and use their `/assets/images/products/...` path in the product `imageUrl`.

No product photos are bundled, so missing catalog imagery uses a neutral illustration rather than unrelated stock photos.
